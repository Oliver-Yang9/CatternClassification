## 链接规则

1. **首页 ↔ 全部**：本页链接所有笔记，每篇笔记顶部可回到本页。
2. **总览 ↔ 各章**：总览索引表指向每一章，每章导航指回总览。
3. **章节序列**：第 N 章与第 N±1 章互链。
4. **语义依赖成对**：A 把 B 列为「出链（依赖/引用）」时，B 必把 A 列为「入链」。
5. **附录 ↔ 各章**：各章指回附录速查，附录按章列出公式出处。
6. **合订本 ↔ 各章**：合订本标注合成来源，各章可跳到合订本。
