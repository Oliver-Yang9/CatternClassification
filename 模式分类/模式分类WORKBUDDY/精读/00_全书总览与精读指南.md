## 0. 这份讲义怎么用

原书是**扫描版 PDF（无文本层）**，无法直接抽取正文，因此本讲义不是摘录，而是按**机械工业出版社官方目录（章、节、小节、页码已逐条核对）**逐节重建的精读笔记。每个小节都标注了原书页码，你可以**摊开原书对照着读**：讲义负责讲清"为什么、怎么算、坑在哪"，原书负责推导细节与图示。

使用建议：

1. **第一遍**只读每章的「章节地图」和「一句话定位」，建立该章的问题意识，再进原书。
2. **第二遍**按小节对照读：先看讲义的「展开讲解」，再回原书看推导，最后用「易错点」自检。
3. **第三遍**只做两件事：手写一遍「关键推导精讲」里的推导，做完「自测题」和「上机练习」。
4. 每章末尾的「与其他章的连接」不要跳过——这本书的难点不在于单个公式，而在于**十章之间的方法谱系**。

## 1. 这是一本什么书

本书第 1 版《模式分类与场景分析》出版于 1973 年，是模式识别领域的奠基性著作。第 2 版保留了统计模式识别与结构模式识别的主干，并补进了此后 25 年间成型的新方法：神经网络、机器学习理论、统计学习理论与支持向量机、隐马尔可夫模型、不变量理论、进化计算等。

它的气质与后来的"算法食谱"类教材不同：**它始终把"最优性"放在第一位**。每一章都在回答同一个问题的不同侧面——

> 在**已知什么**、**未知什么**、**代价是什么**的前提下，怎样做决策才是最优的？当最优不可达时，用什么近似、付出什么代价？

这句话是全书的锚点。读到任何一章，都可以回头问自己：这一章放宽了哪条假设？换来了什么？

## 2. 全书主线：一条假设不断被拆掉的链条

十章可以读成**一条"理想假设被逐条拆除"的链条**，每拆掉一条，就多出一章的方法：

| 步骤      | 假设被拆掉的内容                 | 出现的章节   | 新增的方法体系                        |
| ------- | ------------------------ | ------- | ------------------------------ |
| 起点      | 先验、类条件密度、损失**全部已知**      | 第 2 章   | 贝叶斯决策论、判别函数、正态三情况              |
| 第 1 次拆除 | 密度**形式已知、参数未知**          | 第 3 章   | 最大似然估计、贝叶斯参数估计、EM、HMM          |
| 第 2 次拆除 | 密度**形式也不可靠**             | 第 4 章   | Parzen 窗、$k_n$-近邻、最近邻规则        |
| 第 3 次拆除 | 干脆**不估计密度**，直接学决策边界      | 第 5、6 章 | 线性判别函数、感知器、SVM、多层神经网络          |
| 第 4 次拆除 | 目标函数**不可微 / 非凸 / 离散**    | 第 7 章   | 模拟退火、玻耳兹曼学习、遗传算法               |
| 第 5 次拆除 | 样本**不在欧氏空间里**（离散、符号串、结构） | 第 8 章   | 判定树、串匹配与编辑距离、文法方法              |
| 收束      | 拆完之后，如何判断**哪个方法更好**      | 第 9 章   | 无免费午餐、MDL、偏差-方差、重采样、集成         |
| 扩展      | 连**标签都没有**时怎么办           | 第 10 章  | 混合模型与 EM、k-均值、层次聚类、PCA/ICA/SOM |

第 1 章不在这条链条上，它负责**定义问题与流程**：什么是一个模式识别系统，设计循环包含哪几步。

## 3. 五层结构视图

把十章按"在系统中扮演的角色"重新分组，会更清楚：

| 层次 | 章节 | 中心任务 | 产出物 |
|---|---|---|---|
| 问题定义与最优基准 | 第 1–2 章 | 定义系统与流程；在一切已知时求最小风险决策 | 系统流程图、风险准则、判别函数与判定面 |
| 概率结构的学习 | 第 3–4 章 | 从样本估计类条件密度（参数法 / 非参数法） | 点估计、后验分布、核密度、最近邻规则 |
| 判别函数的学习 | 第 5–6 章 | 绕过密度估计，直接学决策边界 | 感知器、MSE、SVM、多层网络与反向传播 |
| 非凸搜索与非度量数据 | 第 7–8 章 | 处理梯度不可用、数据非数值的情形 | 退火、遗传算法、判定树、串匹配、文法 |
| 泛化、评价与无监督 | 第 9–10 章 | 控制过拟合、公平比较；从无标签数据发现结构 | 重采样、集成、EM、聚类、降维 |

**系统的完整流程**（第 1 章给出，全书反复回扣）：

```
传感器 → 分割与组织 → 特征提取 → 分类器 → 后处理 → 评价 → （反馈到特征/模型/阈值/代价）
```

注意最后那个反馈箭头：模式识别不是"训练一次就完事"，而是**设计—评价—再设计**的闭环。第 9 章的交叉验证、第 3 章的过拟合、第 2 章的代价矩阵，都是这条反馈环路的形式化。

## 4. 贯穿全书的六对张力

读到任何方法，都可以用这六对张力给它定位：

1. **拟合 vs 泛化**：训练误差低不等于测试误差低（3.7、9.3、6.11）。
2. **先验知识 vs 数据证据**：假设越强，所需样本越少；假设错了，代价越大（3.5、9.2）。
3. **最优性 vs 可计算性**：理论最优往往依赖未知分布或指数级计算（2.2、7.2、8.6）。
4. **参数法 vs 非参数法**：前者结构清晰、样本效率高；后者适应性强、局部数据需求大（3 vs 4）。
5. **生成式 vs 判别式**：先估密度再分类，还是直接学边界（2–4 vs 5–6）。
6. **有监督 vs 无监督**：标签给出明确目标；无标签时"类"由准则、距离、尺度共同定义（1.5、10.7）。

## 5. 原书符号约定（读全书前先记住）

| 符号 | 含义 |
|---|---|
| $\omega_1,\dots,\omega_c$ | $c$ 个类别（状态） |
| $\alpha_1,\dots,\alpha_a$ | $a$ 个可能的**动作**（判决），不一定与类别一一对应 |
| $\mathbf{x}\in\mathbb{R}^d$ | $d$ 维特征向量 |
| $P(\omega_i)$ | 先验概率 |
| $p(\mathbf{x}\mid\omega_i)$ | 类条件密度（似然） |
| $P(\omega_i\mid\mathbf{x})$ | 后验概率 |
| $p(\mathbf{x})$ | 证据因子（归一化常数），$p(\mathbf{x})=\sum_i p(\mathbf{x}\mid\omega_i)P(\omega_i)$ |
| $\lambda(\alpha_i\mid\omega_j)$ | 真实类别为 $\omega_j$ 时采取动作 $\alpha_i$ 的损失 |
| $R(\alpha_i\mid\mathbf{x})$ | 条件风险；$R=\int R(\alpha(\mathbf{x})\mid\mathbf{x})p(\mathbf{x})d\mathbf{x}$ 为总风险 |
| $g_i(\mathbf{x})$ | 第 $i$ 类的判别函数，决策规则为取 $\arg\max_i g_i(\mathbf{x})$ |
| $n$ | 训练样本数 |
| $\boldsymbol\mu_i,\ \boldsymbol\Sigma_i$ | 第 $i$ 类的均值向量与协方差矩阵 |
| $\mathcal{D}$ | 训练集 |

**判别函数写法的统一约定**：全书大量使用 $g_i(\mathbf{x})=\ln p(\mathbf{x}\mid\omega_i)+\ln P(\omega_i)$，因为对数变换单调，不影响取最大值的类别，却能把连乘变成求和、把指数变成二次型。

## 7. 精读时的四个习惯

1. **每个公式都问"它依赖于什么假设"**。例如贝叶斯最优依赖"模型和先验都正确"，一旦模型错，最优性立刻消失。
2. **每个算法都问"它在优化什么目标函数"**。感知器优化错分样本到边界的距离之和，SVM 优化间隔，MSE 优化平方误差，反向传播优化交叉熵或均方误差——目标函数决定了算法的全部性格。
3. **每次读"收敛性证明"都问"证明用到了什么"**。感知器收敛需要线性可分；EM 单调上升需要正确的后验；k-均值收敛需要交替优化不增。条件不满足时，结论立刻失效。
4. **自己动手算一遍原书的上机练习**。这本书的价值有一半在习题里：光读不练，第 5、6、10 章几乎等于没读。

## 8. 十个高频误区（精读时反复对照）

| # | 误区 | 正确的说法 |
|---|---|---|
| 1 | 贝叶斯决策在任何数据上都最优 | 只在**模型、先验、损失都正确**时最优；现实中它是最优性的**基准**而非保证 |
| 2 | 最大似然估计无偏且稳定 | 均值估计无偏，但协方差的 ML 估计偏小（因子 $(n-1)/n$），小样本下极不稳定 |
| 3 | "非参数"＝不依赖假设 | 核函数、带宽、邻域大小、距离度量都是强假设，只是形式不同 |
| 4 | 最近邻的渐近界能保证实际效果 | $R^\*\le R\le 2R^\*$ 是 $n\to\infty$ 的结论；高维下"最近"本身因距离集中而失去意义 |
| 5 | 训练集线性可分 ⇒ 模型可靠 | 可分只说明存在解，不说明解稳定、不说明泛化 |
| 6 | 神经网络能逼近一切 ⇒ 一定能训好 | 通用逼近是**表达能力**结论；优化、样本量、正则化是另一回事 |
| 7 | 特征/层数/参数越多越好 | 复杂度必须与样本量、噪声水平匹配，否则过拟合（3.7、9.3） |
| 8 | 用正确率比较分类器就够了 | 类别不平衡、代价不对称、数据泄漏都会让"正确率"严重失真（2.3、9.6） |
| 9 | 聚类结果就是真实类别 | 聚类只在给定的**准则、距离、尺度、类数**下成立，换个准则就换一批类（10.7） |
| 10 | 一次划分的训练/测试足够 | 必须报告数据划分方式、重复次数与不确定性；单一数字不可复现（9.6） |
