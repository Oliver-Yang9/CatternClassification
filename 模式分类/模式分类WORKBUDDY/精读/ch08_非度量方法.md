# 第8章 非度量方法（原书 pp.318–362）

> **一句话定位**：本章回答"当样本不是欧氏空间里的定长实向量——属性是名义的、长度可变的、甚至是一个串或一段结构时，还怎么做分类与描述"。

## 逐节精读

### 8.1 引言（p.318）

**原书要点**
- 前面各章都假设样本是定长实向量、空间上有可用的距离或内积。
- 三类"非度量"数据：名义/序数属性、串（长度可变）、结构化对象。

**展开讲解**
"非度量"不是"没有数学结构"，而是**不能用全局连续可微的目标函数来刻画**：没有距离则第4章的近邻失效，没有向量则第5、6章的梯度无从谈起。三条出路：离散**判定**（树）、离散**距离**（编辑距离）、**文法/规则**。

**易错点**
- 名义属性不能当整数用（"红=1、蓝=2"会凭空引入大小关系）。

### 8.2 判定树（p.318）

**原书要点**
- 内部节点各带一个**查询**，叶节点带类别标记；分类即从根沿分支走到叶。
- 递归构造：在当前节点挑查询把样本分成子集，对子集递归重复。

**展开讲解**
树的本质是**分而治之 + 局部化**：把空间切成盒子，每个盒子投一票。好处是不需要度量假设；坏处是边界为**轴平行**阶梯状（见 8.3.8），且树**不稳定**——样本小变动可能换掉根节点查询，这是树方差大、集成方法要治的病。

**关键公式**
$$g(\mathbf{x})=\omega_{k(\ell)},\quad \ell=\mathbf{x}\text{ 到达的叶节点}$$
- 叶 $\ell$ 上的多数类即其标记。

**易错点**
- 树是**贪心**生长的，不保证全局最优树（找最优树是 NP 难的）。

### 8.3.1 分支数目（p.320）

**原书要点**
- CART 固定**二叉**；名义属性 $k$ 个取值要枚举 $2^{k-1}-1$ 种子集划分。
- 多分支会让 $\Delta i$ 随分支数单调增大，准则偏向分支多的查询。

**展开讲解**
二叉可连续分裂**模拟**任意多分支（表达力不损失），且避免"分支数"污染准则；多分支还会把样本切得更碎。

**易错点**
- 二叉不等于"只能用两个属性"：同一属性可分裂出多个区间。

### 8.3.2 查询的选取与节点不纯度（p.320）

**原书要点**
- $i(N)$ 的性质：全同类最小（0）、均匀分布最大、对类别**对称**。
- 三种不纯度：熵、Gini、误分类；查询 $s$ 的不纯度下降 $\Delta i$，选其最大者。

**关键公式**
$$i(N)_{\text{熵}}=-\sum_j P(\omega_j)\log_2 P(\omega_j),\qquad i(N)_{\text{Gini}}=1-\sum_j P^2(\omega_j)$$
$$i(N)_{\text{误分类}}=1-\max_j P(\omega_j),\qquad \Delta i(s,N)=i(N)-P_L i(N_L)-(1-P_L)i(N_R)$$
- $P(\omega_j)$：属于 $\omega_j$ 的样本比例；$P_L$：分到左子节点的比例；
- 多分支推广：$\Delta i=i(N)-\sum_m P_m i(N_m)$。

**展开讲解**
$\Delta i$ 是**不纯度加权平均的减少量**：父节点不确定性减去分裂后的剩余不确定性。它只用计数不用距离——这正是树能处理名义属性的根本原因。数值属性切点只需检查排序后相邻不同取值之间，且 $\Delta i$ 可**增量更新**。

**易错点**
- $\Delta i$ 不能跨"分支数不同"的查询比——分支越多越大，这是准则的固有偏向。
- 只在熵不纯度下 $\Delta i$ 才叫信息增益；Gini 下降不是互信息。

### 8.3.3 分支停止准则（p.324）

**原书要点**
- 条件：不纯度低于阈值、样本数少于阈值、全同类、$\Delta i$ 不显著、深度上限。
- 阈值必须由**交叉验证**确定。

**展开讲解**
局部停止准则是结构性缺陷：当前增益小不等于往下两层也无用。典型反例是"棋盘/异或"结构——根节点上任何单属性查询的 $\Delta i$ 都接近 0，贪心准则会在根就喊停，这就是**前瞻（lookahead）问题**。CART 的对策是停止准则取松，再用剪枝全局决定哪里该收。

**易错点**
- 停止阈值与剪枝强度是两个旋钮，不要同时用得很紧。

### 8.3.4 剪枝（p.325）

**原书要点**
- 先长成充分大的树 $T_0$，再自底向上把一些子树替换成叶节点。
- 代价复杂度剪枝：误差加叶数惩罚，加大惩罚得一串嵌套子树，用交叉验证挑。

**关键公式**
$$R_\alpha(T)=R(T)+\alpha\,|\tilde T|$$
- $R(T)$：误差/不纯度；$|\tilde T|$：叶节点个数；$\alpha\ge0$：惩罚系数。

**展开讲解**
剪枝与停止准则的区别在**评价视角**：停止是前向局部的，剪枝是后向全局的（比较"整棵子树"与"一个叶"）。$R(T)$ 取自训练数据必偏向大树，故**必须用交叉验证**估计。每个内部节点有"值得剪掉它的临界 $\alpha$"，最小者为"最弱链"——整条路径可一次算出。

**易错点**
- 用训练误差选 $\alpha$ 必然选回最大树（$R$ 随叶数单调不增）。
- "一个标准误"规则取的是误差最小 +1SE 内**最简**的那棵。

### 8.3.5 叶节点的标记（p.326）

**原书要点**
- 默认标为该叶多数类；有代价时标为使条件风险最小的类。

**关键公式**
$$k^*=\arg\max_j P(\omega_j\mid\ell)\ \longrightarrow\ \arg\min_j\sum_k\lambda_{jk}P(\omega_k\mid\ell)$$
- $P(\omega_j\mid\ell)$：叶中属于 $\omega_j$ 的比例；$\lambda_{jk}$：把 $\omega_k$ 判为 $\omega_j$ 的损失。

**易错点**
- 改先验或代价**不必重新长树**：只改叶标记即可（8.3.9）。

### 8.3.6 计算复杂度（p.327）

**原书要点**
- 生长：每节点考察 $d$ 个属性，数值属性排序 $O(n\log n)$ 后扫描切点。
- 分类：只需沿一条路径，$O(\text{树深})$，**与训练样本数无关**。

**展开讲解**
分类的 $O(\text{树深})$ 是树最被低估的优势：第4章的非参数方法测试时要与全部 $n$ 个训练样本比较，树的测试代价却与 $n$ 无关。

**易错点**
- 复杂度里的 $n$ 是**该节点的样本数**，越往下越小。

### 8.3.7 特征选择（p.328）

**原书要点**
- 树是特征选择器：被反复用作查询的属性更重要，靠近根的尤其重要。

**展开讲解**
可用它给属性重要性排序再喂给其他分类器；但 $\Delta i$ 偏向取值多的属性。

**易错点**
- 属性相关时重要性被"摊薄"；树没用到的属性不等于无用。

### 8.3.8 多元判定树（p.329）

**原书要点**
- 节点查询改为线性组合 $\sum_i a_i x_i>\theta$，产生**斜分割**。

**展开讲解**
$\mathbf{a}$ 可在节点内当小型线性判别问题求（第5章感知器、LMS、Fisher），也可用第7章的随机搜索与遗传算法；代价是更难解释。

**易错点**
- 多元树要求属性是数值的；名义属性编码后线性组合语义就模糊了。

### 8.3.9 先验概率和代价函数（p.329）

**原书要点**
- 先验：按 $\pi_k/\hat\pi_k$ 给样本加权；代价：把损失矩阵引进叶标记与剪枝准则。

**展开讲解**
先验与代价可互相折算——某类样本加权 $c$ 倍等价于把误判该类的损失放大 $c$ 倍，所以**只改一处**，否则代价被乘两次。

**易错点**
- 用重采样实现加权时，会改变"样本数阈值"的语义。

### 8.3.10 属性丢失问题（p.330）

**原书要点**
- 训练时缺失：计算某属性的 $\Delta i$ 时只用该属性已知的样本。
- 测试时缺失：用**替代分裂**（训练时预存与主分裂最一致的备用属性）。

**展开讲解**
替代分裂的巧妙在于**备用钥匙要在训练时配好**。另一点常被忽略：**缺失本身可能携带信息**（如"没做这项检查"），此时应显式编码成一个新取值。

**易错点**
- 训练时直接丢弃含缺失的样本会引入选择偏差。

### 8.4.1 ID3（p.331）

**原书要点**
- Quinlan 提出，**多分支**（每个取值一条分支），用**信息增益**选属性。
- 原始版本只处理名义属性、无剪枝。

**易错点**
- 信息增益偏向取值多的属性（给每个样本唯一取值，纯度立刻为 1，泛化为零）。

### 8.4.2 C4.5（p.332）

**原书要点**
- 用**增益率**：除以分支本身的信息量，惩罚取值多的属性。
- 支持连续属性、缺失值、**后剪枝**、可导出规则集。

**关键公式**
$$\text{增益率}=\frac{\Delta i_{\text{熵}}(s,N)}{-\sum_m P_m\log_2 P_m}$$
- 分子即信息增益；分母是分支划分的熵——分支越碎分母越大。

**易错点**
- 分母接近 0 时增益率不稳定，常先用增益筛一轮再排增益率。

### 8.4.3 哪种树分类器是最优的（p.332）

**原书要点**
- 不存在普遍最优的树分类器；各种树之间差别通常不大。
- 影响更大的是**复杂度控制**（剪枝/停止准则）与数据本身。

**展开讲解**
看到"某树优于某树"时先看它是否做了复杂度调优——只比未剪枝的树，比的其实是过拟合程度。

**易错点**
- 没有免费午餐：某数据集上的排序不代表另一数据集上的排序。

### 8.5.1 串匹配（p.334）

**原书要点**
- 串是取自某字母表的符号序列（字符、音素、碱基、笔画码）。
- 模板匹配：把未知串与各类代表串比较，取最相近者所属的类。

**展开讲解**
长度可变是麻烦的根源：两个长度不同的串必须先决定"谁和谁对位"，即**对齐**问题。允许错位就要分别计价，于是引出**编辑距离——"带对齐的串距离"**。

**易错点**
- 串不能当定长向量做减法；顺序信息是其核心。

### 8.5.2 编辑距离（p.336）

**原书要点**
- 三种操作：**插入**、**删除**、**替换**，各有代价；编辑距离是变为目标串的最小总代价。
- 用动态规划求解，并用回溯指针给出最优对齐。

**关键公式**
$$D(i,j)=\min\begin{cases}D(i-1,j)+c_{\text{del}}(x_i)\\ D(i,j-1)+c_{\text{ins}}(y_j)\\ D(i-1,j-1)+c_{\text{sub}}(x_i,y_j)\end{cases}$$
初值 $D(0,0)=0$，$D(i,0)=\sum_{t\le i}c_{\text{del}}(x_t)$，$D(0,j)=\sum_{t\le j}c_{\text{ins}}(y_t)$。
- $D(i,j)$：$X$ 前 $i$ 个字符与 $Y$ 前 $j$ 个字符间的最小代价；三项对应删、插、对位。

**展开讲解**
递推成立是因为最优对齐的最后一步只有三种可能，且删掉最后一步剩下仍须是最优子对齐（**最优子结构**）；大量路径经过同一 $(i,j)$（**重叠子问题**）故可存表复用。**代价函数就是领域知识的注入口**。

**易错点**
- 三项不能漏；只取对角线那项会退化成"逐位比较"。

### 8.5.3 计算复杂度（p.338）

**原书要点**
- 时间 $O(nm)$、空间 $O(nm)$；只求距离时可用滚动数组降到 $O(\min(n,m))$。

**易错点**
- 要回溯路径就必须保留整张表（或分治重算）。

### 8.5.4 容错的串匹配（p.338）

**原书要点**
- "匹配"变成"编辑距离不超过阈值"，从而容忍噪声与错配。
- 在长文本中查找短模式：首行全 0（任意起点）、取末行最小值（任意终点）。

**展开讲解**
"改两行初始化就换一个问题"：**递推式描述局部结构，边界条件描述任务定义**。

**易错点**
- 阈值要与串长挂钩，否则长串天然更容易超过阈值。

### 8.5.5 带通配符的串匹配（p.339）

**原书要点**
- 通配符（don't care）可与任意符号匹配，替换代价取 0；DP 结构不变。

**易错点**
- 代价设 0 时要防"全用通配符"成为退化解。

### 8.6.1 文法（p.340）

**原书要点**
- 文法 $G=(N,\Sigma,P,S)$：非终结符集 $N$、终结符集 $\Sigma$、产生式集 $P$、起始符 $S$。
- 从 $S$ 反复重写得**句型**；只含终结符者为**句子**；全体句子构成语言 $L(G)$。

**展开讲解**
（以下为说明性示例，不代表原书的具体例子）取 $P=\{S\to aSb,\ S\to ab\}$，则 $L(G)=\{a^nb^n\mid n\ge1\}$，它需"计数"故无法用正则文法描述。可见**文法是对集合的有限描述**，有限规则可描述无穷多对象，这正是它强于"枚举模板"之处。

**易错点**
- 非终结符是中间变量，最终必须全部消掉；终结符才是输入串里的符号。

### 8.6.2 串文法的类型（p.341）

**原书要点**
- Chomsky 四层：0 型无限制（图灵机）；1 型上下文有关（线性有界自动机）；2 型上下文无关 CFG，$A\to\alpha$（下推自动机）；3 型正则，$A\to aB$ 或 $A\to a$（有穷自动机）。
- 模式识别中最常用正则文法（局部约束）与 CFG（嵌套结构）。

**展开讲解**
选型依据是"结构有多复杂"：只需"不允许某两符号相邻"，正则文法足够且识别 $O(n)$；要描述"括号配对""形状递归构成"这类嵌套，必须用 CFG，识别升到 $O(n^3)$ 量级。

**易错点**
- 层级是包含关系；"用高层文法写"不等于该语言真的需要高层。

### 8.6.3 利用文法的识别（p.343）

**原书要点**
- 任务：给串 $\mathbf{x}$ 与文法 $G$，判定 $\mathbf{x}\in L(G)$，并给出**推导/解析树**。
- 两条路线：自顶向下（从 $S$ 推导）与自底向上（把子串归约为非终结符）。
- CFG 化 Chomsky 范式后可用 CYK；一般 CFG 用 Earley，$O(n^3)$；正则文法用有穷自动机，$O(n)$。

**展开讲解**
文法方法的独特价值是**输出结构**：第2–6章只回答"属于哪一类"，解析树回答"由哪些部分、按什么关系构成"。代价是文法要由专家设计，且一旦有歧义，识别须同时考虑所有推导。

**易错点**
- 识别（有文法判串）与推断（8.7，从串学文法）难度完全不同。
- 自顶向下在文法含左递归时会无限循环，需先改写文法。

### 8.7 文法推断（p.345）

**原书要点**
- 任务：从样本串（通常还分正例/反例）反推文法 $G$。
- 有限样本总有无穷多个相容文法，问题**欠定**，必须引入归纳偏置（偏好状态数最少）。
- 正则文法推断：先构造接受全部正例的最大自动机（如前缀树），再**合并状态**逐步泛化。
- 理论负结果：仅凭正例不能可靠识别正则语言（identification in the limit）；给反例则可学。

**展开讲解**
它的失败不是**优化上的**而是**信息上的**：状态数最少、第二少……的文法都能生成同一批样本，却对未见串给出不同判定。工程折中是：**人工定文法结构，只从数据估产生式概率**（随机文法/概率 CFG）。

**易错点**
- "训练串都能生成"不构成成功证据——接受一切串的平凡文法也能做到。

### 8.8 基于规则的方法（p.347，选读）

**原书要点**
- 产生式系统：一组 IF（条件）THEN（结论）规则，条件是对属性的合取测试。
- 与树的差别：规则可**重叠**、可**不完备**（无匹配时可拒绝），可独立排序增删。
- 冲突消解：多条同时匹配时按特异度、代价、置信度或加权投票决定。
- 顺序覆盖：每次学一条覆盖尽量多正例、尽量少负例的规则，删掉已覆盖样本，重复。

**展开讲解**
树与规则是同一知识的两种组织方式：**树强制互斥且完备**，规则允许重叠与空缺。空缺带来"拒绝"能力，重叠带来更紧凑的表达。

**易错点**
- 从树抽出的规则集不再互斥，须重新规定冲突消解与默认类。

## 关键推导精讲

### 推导一：不纯度下降就是信息增益（8.3.2）

**第 1 步**：$\Delta i(s,N)=i(N)-P_L i(N_L)-(1-P_L)i(N_R)$。用加权平均而非简单相加，是因为子节点大小不同，大子节点的纯度更该被重视。

**第 2 步**：$i(N)$ 是"不知任何属性时判断类别所需的信息量"；$P_L i(N_L)+(1-P_L)i(N_R)$ 是"已知落在哪个分支后**平均**还需多少信息"，即条件熵。

**第 3 步**：套用互信息定义
$$\Delta i(s,N)=H(\omega)-H(\omega\mid s)=I(\omega;s)$$
故在熵不纯度下，**最大化 $\Delta i$ 等价于最大化查询与类别的互信息**。

**假设与失效**：(a) $P(\omega_j)$ 用节点频率估计，样本少时增益被高估——这是"偏向取值多的属性"与"多分支增益偏大"共同的统计根源；(b) 结论**只对熵不纯度成立**，Gini 下降是方差型准则。

**第 4 步（为何要增益率）**：若属性把样本分成 $n$ 个单样本分支，各子节点熵为 0，$\Delta i=i(N)$ 最大——增益被"碎"抬高，除以分支分布的熵即得增益率（8.4.2）。

### 推导二：编辑距离的动态规划递推（8.5.2）

**第 1 步（定义子问题）**：$D(i,j)$ = 把 $X$ 的前缀 $x_1\ldots x_i$ 变成 $Y$ 的前缀 $y_1\ldots y_j$ 的最小代价。**用前缀定义是关键**——状态只有两个整数，依赖是局部的。

**第 2 步（考察最后一步）**：任何对齐的最后一步必是三种情形之一：$x_i$ 被**删除**（前序 $D(i-1,j)$）、$y_j$ 被**插入**（前序 $D(i,j-1)$）、$x_i$ 与 $y_j$ **对位**（前序 $D(i-1,j-1)$）。

**第 3 步（最优子结构）**：若前序还有更便宜的做法，换进去就得到总成本更低的整个对齐，与整体最优矛盾（**剪贴论证**）。

**第 4 步（边界）**：$D(0,0)=0$；$D(i,0)$ 只能一路删除，$D(0,j)$ 只能一路插入。边界不是形式而是**任务定义**——8.5.4 就是换掉边界。

**第 5 步（填表与复杂度）**：$D(i,j)$ 只依赖左、上、左上三格，按行递增填表，每格 $O(1)$，共 $nm$ 格 → 时间 $O(nm)$。要回溯需存指针 → 空间 $O(nm)$；只求距离可用滚动数组 → $O(\min(n,m))$。

**假设与失效**：(a) 代价须**可加**且只依赖本次操作，否则最优子结构失效（如"连续插入"有打包折扣就要扩展状态）；(b) 若允许**转位**（相邻两段交换），递推需加 $D(i-2,j-2)+c_{\text{trans}}$；(c) 该距离不保证满足三角不等式。

```text
【算法 1：CART 生长 + 代价复杂度剪枝（8.3.2–8.3.4）】
===== 生长 =====
输入：训练集 D，属性集，停止准则（最小样本数 n_min、不纯度阈值 β）   输出：充分生长的树 T0
grow(N, D_N):
    if D_N 全属同一类 或 |D_N| < n_min 或 i(N) < β:      # 8.3.3，此处取松
        N 标为叶，标记 argmax_j P(ω_j|N)（有代价则取最小风险）; return
    对每个属性 a：                                        # 8.3.1 二叉
        数值属性：排序后扫描相邻取值之间的切点，增量更新 Δi
        名义属性：枚举取值子集划分（k 个取值 → 2^(k-1)-1 种）
    取使 Δi(s,N) = i(N) - P_L·i(N_L) - (1-P_L)·i(N_R) 最大的 (a*, θ*)
    记录主分裂；按与主分裂划分的一致性排序，记录替代分裂          # 8.3.10
    按 (a*,θ*) 分成 D_L, D_R，递归 grow(左), grow(右)
复杂度：每节点 O(d·|D_N|·log|D_N|)；整树约 O(d·n·log n·深度)；分类 O(树深)

===== 剪枝 =====
输入：T0，惩罚系数网格 α，交叉验证折数 K      输出：选中的子树 T*
for 每个 α：
    自底向上：对每棵子树 t，比较"保留 t"与"用叶替换 t"的 R_α = R + α·|叶数|
    若替换后 R_α 不增大则剪掉（最弱链优先），得嵌套序列 T0 ≻ T1 ≻ ... ≻ {根}
用 K 折交叉验证估计每棵候选子树的误差 R_cv(T)   # 关键：不能用训练误差选 α
T* = argmin_T R_cv(T)；或用"一个标准误"规则取 R_cv 最小 +1SE 内最简的子树
复杂度：候选序列一次算出，代价 O(|T0|)；交叉验证 O(K × 候选数 × n)
```

```python
# 【算法 2：编辑距离动态规划（8.5.2–8.5.5）】
def edit_distance(X, Y, c_ins, c_del, c_sub, want_align=False):
    """c_sub(x,y) 为替换代价；通配符只需令 c_sub('*', y) = 0"""
    n, m = len(X), len(Y)
    D = [[0.0]*(m+1) for _ in range(n+1)]
    bp = [[None]*(m+1) for _ in range(n+1)] if want_align else None
    for i in range(1, n+1):                 # 边界：只能一路删除
        D[i][0] = D[i-1][0] + c_del(X[i-1])
    for j in range(1, m+1):                 # 边界：只能一路插入
        D[0][j] = D[0][j-1] + c_ins(Y[j-1])
    for i in range(1, n+1):
        for j in range(1, m+1):
            cand = ((D[i-1][j]   + c_del(X[i-1]),       'del'),
                    (D[i][j-1]   + c_ins(Y[j-1]),       'ins'),
                    (D[i-1][j-1] + c_sub(X[i-1],Y[j-1]), 'sub'))
            v, a = min(cand, key=lambda t: t[0]); D[i][j] = v
            if want_align: bp[i][j] = a
    # 近似子串匹配（8.5.4）：初始化首行全 0、取末行最小值即为局部匹配
    return (D[n][m], bp) if want_align else D[n][m]
# 复杂度：时间 O(n·m)；空间 O(n·m)（要回溯）或 O(min(n,m))（滚动数组）
```

```text
【算法 3：上下文无关文法的 CYK 识别（8.6.3，Chomsky 范式）】
输入：串 x = x_1...x_n，CFG 的 Chomsky 范式（产生式为 A→BC 或 A→a）
输出：是否 x ∈ L(G)；若是则给出解析树
初始化：对每个位置 i 与每条终结符产生式 A→x_i，把 A 填入 T[i][i]
for 长度 len = 2..n:
    for 起点 i = 1..n-len+1:
        k = i + len - 1                                  # 终点
        for 切分点 s ∈ [i, k):
            for 每条产生式 A→BC：
                if B ∈ T[i][s] 且 C ∈ T[s+1][k]: 把 A 加入 T[i][k]
判定：起始符 S ∈ T[1][n] ?          # 通过回填指针可重建解析树
复杂度：时间 O(n^3·|P|)，空间 O(n^2·|N|)
注：非 CFG 需先化为 Chomsky 范式；一般 CFG 也可用 Earley（同为 O(n^3) 量级，
    对无歧义文法更快）；正则文法直接构造有穷自动机，识别只需 O(n)
```

## 本章必背 5 条

1. **树能处理非度量数据，是因为它只用计数不用距离**：$\Delta i(s,N)=i(N)-P_L i(N_L)-(1-P_L)i(N_R)$ 只用各类样本比例，故名义、序数、数值属性可在同一准则下竞争。
2. **熵不纯度下的 $\Delta i$ 就是信息增益**：由 $H(\omega)-H(\omega\mid s)=I(\omega;s)$ 直接得；改成 Gini 或误分类后它**不再是**互信息。多分支时 $\Delta i$ 偏向分支多的查询，这是增益率的唯一动机。
3. **先长过头再剪，不要在中间喊停**。贪心停止准则看不见"往下两层才出现的规律"（前瞻问题）；剪枝比较"整棵子树 vs 一个叶"，且必须用交叉验证估计误差——用训练误差选 $\alpha$ 必然选回最大树。
4. **编辑距离 = 带对齐的串距离**。三项对应删除、插入、替换，依据是**最优子结构**（剪贴论证）与**重叠子问题**；代价函数是领域知识的注入口。
5. **文法给出的是结构描述，不是类别标签**。识别（有文法判串）与推断（从串学文法）难度不同：后者欠定，需"偏好最简文法"这类归纳偏置，且仅凭正例理论上无法可靠识别正则语言。

2. **编辑距离：从"能算距离"到"能做识别"**：实现带回溯指针的版本，先做单元测试（相同串距离为 0）。再做三项扩展：(a) 设计**非平凡**替换代价（按键盘相邻度或字符相似度），与"全代价为 1"比较召回率；(b) 改为半全局匹配，在长文本中搜短模式；(c) 加通配符，观察"全用通配符"的退化解并给小正代价修正。最后改成滚动数组版本，验证距离不变但要回溯时必须保留全表。

3. **复杂度旋钮与特征重要性扫描**：扫"最小叶样本数 × 剪枝强度 $\alpha$"网格，每格做 $K$ 折交叉验证画误差等高线。再统计每个属性在所有分裂中的 $\Delta i$ 之和，排序后逐步剔除最不重要的属性重训，画"测试误差 vs 保留属性数"曲线（8.3.7）。
